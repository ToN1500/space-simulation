# แบบจำลองฟิสิกส์ดาราศาสตร์และกาลอวกาศ 3 มิติ (3D Relativistic Space Simulation Interactive App)

แบบจำลองฟิสิกส์ดาราศาสตร์เชิงโต้ตอบ 3 มิติ (3D Interactive Astrophysics Simulation) บนเว็บเบราว์เซอร์ ที่จำลองปรากฏการณ์ทางจักรวาลวิทยาที่สำคัญ 3 รูปแบบ ได้แก่ **กาแล็กซีทางช้างเผือก (Milky Way Galaxy)**, **เลนส์ความโน้มถ่วงรอบหลุมดำมวลยิ่งยวด (Supermassive Black Hole Gravitational Lensing)** และ **การรวมตัวแผ่คลื่นความโน้มถ่วงของระบบดาวคู่ (Binary Neutron Star Inspiral & Kilonova)** เรนเดอร์บนเทคโนโลยี WebGL (Three.js) เพื่อประสิทธิภาพการแสดงผลระดับ 60 FPS

> [!NOTE]
> **ข้อมูลผู้พัฒนาและเครื่องมือสร้างสรรค์ (AI Co-Creation)**
> โปรเจกต์นี้ได้รับการพัฒนาและปรับปรุงฟิสิกส์โดย **ผู้พัฒนา (USER)** ร่วมกับ **Antigravity** (เอเจนต์ AI อัจฉริยะสำหรับเขียนโค้ด พัฒนาโดยทีมงาน **Google DeepMind**) ภายใต้กรอบการ pair programming เชิงลึกและการคำนวณดาราศาสตร์เชิงคณิตศาสตร์ฟิสิกส์จริง

## 🚀 วิธีการติดตั้งและเริ่มต้นใช้งาน (Quick Start)

หากต้องการรันตัวจำลองนี้บนคอมพิวเตอร์ของคุณ ให้ทำตามขั้นตอนดังต่อไปนี้:

### 1. ความต้องการของระบบ (Prerequisites)
เครื่องคอมพิวเตอร์ของคุณต้องติดตั้ง **Node.js** (แนะนำเวอร์ชัน 18.0.0 ขึ้นไป) โดยสามารถดาวน์โหลดได้ที่ [nodejs.org](https://nodejs.org/)

### 2. ขั้นตอนการติดตั้ง Dependencies
เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์ของโปรเจกต์นี้ แล้วรันคำสั่ง:
```bash
npm install
```

### 3. รันตัวจำลองสำหรับใช้งานทั่วไป (Development Mode)
เมื่อติดตั้งเสร็จเรียบร้อย ให้รันคำสั่งนี้เพื่อเริ่มใช้งานระบบจำลอง:
```bash
npm run dev
```
ระบบจะเปิดพอร์ตการทำงานขึ้นมา ให้คุณเข้าชมเว็บจำลองได้ผ่านที่อยู่:
👉 **http://localhost:5173/** (หรือพอร์ตอื่นตามที่แสดงบนหน้าจอ Terminal)

### 4. การคอมไพล์โปรเจกต์เพื่อส่งออกบริการจริง (Production Build)
หากต้องการส่งออกไฟล์เว็บแอปพลิเคชันนี้เพื่อขึ้นโฮสติ้งจริง (เช่น Vercel, Netlify) สามารถรันคำสั่ง:
```bash
npm run build
```
ระบบจะคอมไพล์ซอร์สโค้ดและสร้างโฟลเดอร์ชื่อ `dist` ซึ่งบรรจุไฟล์ HTML, CSS และ JS ที่บีบอัดแล้วเรียบร้อยพร้อมนำขึ้นเซิร์ฟเวอร์

## 📂 โครงสร้างโฟลเดอร์ของโปรเจกต์ (Directory Structure)

โปรเจกต์ได้รับการออกแบบโครงสร้างแบบแยกส่วนอิสระ (Modular Architecture) เพื่อการบำรุงรักษาและต่อขยายได้ง่าย:
*   `index.html` — โครงสร้างหน้าเว็บหลักและแผงควบคุม Sci-Fi Overlay ในธีม Glassmorphism
*   `src/main.js` — ตัวประสานงานหลัก (Entry Point) ทำหน้าที่ตั้งค่า Scene, Camera, WebGLRenderer, Controls, UI Events และการผูกลูปเวลาเชิงแมนวลเพื่อหลีกเลี่ยง Clock สะดุดค้าง
*   `src/galaxy.js` — โมดูลสร้างและคำนวณวงโคจรดวงดาวในแขนกาแล็กซีทางช้างเผือก (Milky Way)
*   `src/blackhole.js` — โมดูลจำลองหลุมดำมวลยิ่งยวดและปรากฏการณ์เลนส์ความโน้มถ่วง (Gravitational Lensing)
*   `src/binarystar.js` — โมดูลประมวลฟิสิกส์ระบบดาวคู่แผ่คลื่นความโน้มถ่วง, การเปลี่ยนผ่านชนปะทะแบบ Smooth Merger, และการจำลองตาข่ายกาลอวกาศดิ่งลึก
*   `src/style.css` — ไฟล์สไตล์ CSS ตกแต่งความงาม Sci-Fi HUD คอนโทรลพาเนล

## 🧠 ทักษะและองค์ความรู้ที่ได้รับจากโปรเจกต์นี้ (Key Learnings & Portfolio Value)

โปรเจกต์นี้ไม่ใช่เพียงแค่การเขียนโค้ดให้ระบบแสดงผลภาพ แต่เป็นการประยุกต์ใช้ความรู้บูรณาการเชิงลึกระหว่าง **ดาราศาสตร์ฟิสิกส์ (Astrophysics)** และ **วิศวกรรมซอฟต์แวร์ระดับสูง (Advanced Software Engineering)** ซึ่งช่วยเพิ่มมูลค่าให้แก่ Portfolio ของผู้พัฒนาในมิติต่างๆ ดังนี้:

### 1. ด้านดาราศาสตร์ฟิสิกส์ (Astrophysics & Cosmology)

*   **สัมพัทธภาพทั่วไปและเลนส์ความโน้มถ่วง (3D Gravitational Lensing)**:
    เรียนรู้คณิตศาสตร์ที่อธิบายแรงดึงดูดของหลุมดำต่อแสง โดยประยุกต์ใช้ **สมการเลนส์ความโน้มถ่วงของจุดมวล (Point-Mass Gravitational Lens Equation)**:
    $$d'_{ideal} = \frac{1}{2} \left(d_{perp} + \sqrt{d_{perp}^2 + 4 R_E^2}\right)$$
    มาคำนวณตำแหน่งการโค้งงอของเส้นแสงจากจานพอกพูนมวล (Accretion Disk) อ้อมผ่านขอบฟ้าเหตุการณ์ (Event Horizon) ขึ้นมาปรากฏบนสายตาผู้สังเกตแบบเรียลไทม์ตามทิศทางการหมุนของมุมกล้อง 3 มิติ
*   **ปรากฏการณ์ความสว่างสัมพัทธภาพ (Relativistic Doppler Boosting)**:
    เข้าใจความแปรผันของความสว่างตามสัมพัทธภาพพิเศษ โดยจานพอกพูนมวลฝั่งที่เคลื่อนที่พุ่งเข้าหาผู้สังเกตจะมีความยาวคลื่นหดสั้นลงส่งผลให้สว่างสดใสขึ้น (Doppler Beaming) ส่วนฝั่งที่วิ่งหนีจะมืดจางลง
*   **วิวัฒนาการดาวคู่และการแผ่คลื่นความโน้มถ่วง (Binary Inspiral & Gravitational Waves)**:
    ทำความเข้าใจการสูญเสียพลังงานวงโคจรจากการปล่อยคลื่นความโน้มถ่วงตามสมการพลังงานคลื่นความโน้มถ่วงเชิงคาบ ส่งผลให้เกิดการชนรวมตัวแบบ **Chirp Effect** (ความถี่ของคลื่นสั่นและพุ่งชนถี่ยิบขึ้นเมื่อระยะห่างลดลง)
*   **กฎการอนุรักษ์มวลและพลังงานในนิวเคลียร์ฟิสิกส์ (Mass-Energy Conservation & r-process)**:
    เรียนรู้ว่าหลังจากการรวมตัวของดาวนิวตรอน มวลรวมของระบบจะสูญเสียไปประมาณ $6\%$ (แปรเปลี่ยนเป็นคลื่นความโน้มถ่วง $3\%$ และเป็นซากมวลสารแผ่รังสีพลังงานสูง Kilonova Ejecta $3\%$) ซึ่งโค้ดจำลองได้นำไปคำนวณลดทอนมวลหลุมดำซากจริงใน Telemetry และคำนวณลดทอนรัศมีชวาร์สชิลด์ ($R_s$) พร้อมทั้งจำลองการเปลี่ยนแปลงสีของฝุ่นละอองนิวตรอนตามอุณหภูมิที่ลดลงจากการขยายตัวแบบ Adiabatic (ปฏิกิริยาการจับนิวตรอนแบบรวดเร็ว - r-process nucleosynthesis)
*   **การบิดเบี้ยวของตาข่ายปริภูมิเวลา (Relativistic Spacetime Grid)**:
    จำลองกรวยแรงโน้มถ่วง (Gravitational Funnel) ที่ยุบตัวดิ่งลึกสูงสุดถึงระดับ **-24.0** ในเฟสหลุมดำ ซึ่งสะท้อนแนวคิดเชิงคณิตศาสตร์ของความบิดโค้งของกาลอวกาศรอบวัตถุที่มีมวลหนาแน่นสูงเป็นอนันต์ (Singularity)

### 2. ด้านวิศวกรรมซอฟต์แวร์และคอมพิวเตอร์กราฟิก (Software & 3D Graphics Engineering)

*   **คณิตศาสตร์ 3 มิติและการประมวลเวกเตอร์ (Vector & Quaternion Mathematics)**:
    เรียนรู้การประยุกต์ใช้เวกเตอร์สายตากล้อง (Camera Space Viewport Up/Right/Direction) และ Quaternions ในการรักษาแนวองศาของ Einstein Ring ให้หันเผชิญหน้าผู้ชมตรงๆ เสมอในทุกมุมการโคจรของกล้อง และนำมาใช้ Dot Product หาตำแหน่งความลึกและมุมเพื่อจัดลำดับ Depth Sorting ป้องกันไม่ให้อนุภาคกราฟิกเกิดการกะพริบสะดุดเวลาหมุนกล้อง
*   **การบริหารจัดการหน่วยความจำและหน่วยประมวลผล (Memory & CPU Optimization)**:
    หลีกเลี่ยงปัญหา Memory Leak บนเบราว์เซอร์จากการสร้าง Mesh และ Canvas Texture ซ้ำซากเมื่อสลับโหมด ด้วยการออกแบบ caching สินทรัพย์ดิจิทัล (Star Texture) ไว้ที่หน่วยความจำส่วนกลาง และส่งต่อตัวแปรเข้าไปในโมดูลต่างๆ อีกทั้งยังระบุการใช้ `.dispose()` บน Geometry และ Material ทุกชิ้นที่ถูกถอดถอนออกจากซีน
*   **การควบคุมเวลาแบบแมนวลในอนิเมชันลูป (Time-Delta Synchronized Loops)**:
    แก้ปัญหาอาการเวลาแช่แข็งหรือการเคลื่อนไหวที่ผิดรูปเมื่อผู้ใช้ทำการคลิกสลับแท็บเมนูหรือกดรีเซ็ต โดยหลีกเลี่ยงการจับคู่เวลาขัดแย้งของ Three.js และใช้การคำนวณ `delta = time - lastTime` แบบแมนวลในลูป Render เพื่อควบคุมการอัปเดตฟิสิกส์ให้มีความราบรื่นต่อเนื่อง
*   **การจัดโครงสร้างแบบ Modular JavaScript (ES6 Modules)**:
    ฝึกฝนการแยกหน้าซอร์สโค้ดควบคุม UI ดั้งเดิมออกจากตัวคำนวณฟิสิกส์กราฟิกสามมิติ เพื่อให้โครงสร้างโค้ดเป็นระบบระเบียบตามมาตรฐานวิศวกรรมซอฟต์แวร์สากล
*   **การออกแบบแผงควบคุม Sci-Fi Glassmorphism (UI/UX Design)**:
    ออกแบบและพัฒนาระบบ Scientific Telemetry Dashboard ที่ดึงข้อมูลเชิงตัวเลข (mass, speed, period, frequency) จาก Engine สามมิติออกแสดงผลแบบเรียลไทม์เพื่อสร้าง UI/UX ในธีม Sci-Fi ที่ตอบสนองการเปลี่ยนแปลงพารามิเตอร์ของผู้ใช้ได้อย่างยอดเยี่ยม

## 🎮 คู่มือการควบคุมแบบจำลอง (Controls Guide)

*   **คลิกซ้าย + ลากเมาส์**: หมุนมุมกล้องรอบวัตถุสามมิติ (3D Orbit)
*   **หมุนสกรอลล์เมาส์**: ซูมเข้า (Zoom In) หรือซูมออก (Zoom Out) เพื่อดูรายละเอียดกรวยกาลอวกาศ
*   **คลิกขวา + ลากเมาส์**: เลื่อนแกนตัศนียภาพของกล้อง (Pan)
*   **แถบควบคุมพารามิเตอร์**:
    *   *โหมดทางช้างเผือก*: ปรับจำนวนดาว ความหนาแน่นของแขนกาแล็กซี ความเร็ว และโทนสี
    *   *โหมดหลุมดำ*: ปรับขนาดมวลหลุมดำ ปริมาณอนุภาคในจานสะสม และความบิดเบี้ยวแรงโน้มถ่วง
    *   *โหมดดาวคู่*: ปรับมวลดาวนิวตรอน ระยะห่าง อัตราสูญเสียพลังงาน และปุ่ม Trigger เพื่อสั่งชนทันที
